# Emploi-kids 📚

بوابة استعمال الزمن المدرسي — الثانوية التأهيلية عبد الكريم الرايس (فاس) — الموسم الدراسي 2026 – 2027.

Portail web interactif et moderne des emplois du temps scolaires :
* **حمزة (Hamza)** : الأولى بكالوريا — علوم تجريبية خيار فرنسية (`1 بك ع ت خ ف 2`)
* **آدم وريان (Adam & Rayane)** : الثانية بكالوريا — علوم فيزيائية خيار فرنسية (`2 بك ع ف خ ف 1` · 31 ساعة)

## المميزات | Fonctionnalités
- 📍 **تحديد تلقائي فوري لليوم الحالي (Jour J)** مع إبراز الحصة الجارية الآن في الوقت الفعلي (`● جارية الآن`).
- 📄 **تحميل فوري لملف PDF (A4 Paysage)** بدون أي اقتطاع أو تشويه.
- 🖨️ **زر طباعة مباشرة فائقة الدقة** مع دعم كامل لمعايير A4.
- 📱 **تصميم متجاوب بالكامل** متوافق مع كافة الأجهزة (هواتف، أجهزة لوحية، حواسيب).
- 🔗 **بوابة رئيسية (`index.html`)** للولوج المباشر بنقرة واحدة إلى كلا الجدولين مع أزرار تنقل للعودة.
